# ارائه تصویری مقاله (آفلاین)

ارائه ویدیومانند ۲۸ صحنه‌ای به فارسی درباره مقاله «ایجنت چه چیزی را باید فراموش کند؟». با زیرنویس، شکل‌های مقاله، جدول‌ها و نمودارهای آماری.

## اجرا (بدون اینترنت)

- **ساده‌ترین راه:** روی `index.html` دوبار کلیک کنید، یا `start.bat` را اجرا کنید.
- **با سرور محلی (اختیاری):** در همین پوشه اجرا کنید:

  ```
  python -m http.server 8000
  ```

  سپس در مرورگر باز کنید: http://localhost:8000

هیچ فایلی از اینترنت بارگذاری نمی‌شود: فونت‌ها در `assets/fonts` و شکل‌ها در `assets/figures` هستند.

## کنترل‌ها

| کلید | کار |
|---|---|
| Space | پخش / توقف |
| ← | صحنه بعد |
| → | صحنه قبل |

دکمه «تمام‌صفحه» و تنظیم سرعت (۰٫۸× تا ۱٫۵×) هم وجود دارد. روایت صوتی فقط وقتی فعال می‌شود که سیستم‌عامل صدای فارسی داشته باشد؛ در غیر این صورت زیرنویس را دنبال کنید.

## ساختار

```
presentation/
├── index.html        صحنه‌ها
├── styles.css        طراحی
├── narration.js      متن روایت هر صحنه
├── app.js            پخش‌کننده و نقشه حرارتی
├── start.bat         باز کردن ارائه در ویندوز
└── assets/
    ├── fonts/        Vazirmatn، Lalezar، IBM Plex Mono (مجوز SIL OFL)
    └── figures/      شکل‌های ۱ تا ۶ مقاله
```

برای به‌روزرسانی شکل‌ها پس از اجرای دوباره آزمایش‌ها، فایل‌های `code/figures/*.png` را در `assets/figures/` کپی کنید.
